# College Python Practicals — Laptop/Online Compiler Files

These three programs are based on the uploaded PDFs:
- Practical No. 4: Math and Random modules
- Practical No. 5(a): Linear Search without functions
- Practical No. 6: Lambda functions and List Comprehension

## How to run
1. Open https://www.programiz.com/python-programming/online-compiler/
2. Open one `.py` file on your device and copy all its code.
3. Paste the code into the online compiler.
4. Click Run.
5. For Practical 5(a), enter the sample input shown in the PDF or use the example below.

## Sample input for Practical 5(a)
Number of elements: 4
Elements: 12, 15, 10, 3
Search value: 10

Expected key result:
The index at which 10 can be found is 2

## Note
Practical 4 uses random operations, so its random values will change each time it runs.
